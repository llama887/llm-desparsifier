Keep one general prompt for all PuzzleScript games. The prompt may define internal categories or if/else branches when the game text justifies them, but categories must be inferred from WINCONDITIONS, RULES, LEGEND aliases, COLLISIONLAYERS, and current state properties, not from memorized game titles. For each branch, preserve base-prompt robustness: solved states return 0.0, estimates stay finite and nonnegative, uncertain mechanics fall back to reachable interaction distance plus score_normalized progress, and large/deadlock penalties require rule-level evidence that the condition is irreversible.
